Pushing Your First Project to GitHub

A Beginner's Guide to Git and GitHub

What is GitHub?

GitHub is an online platform where developers can store, manage, and share their code using Git.

Steps to Push Your First Project

Step 1: Create a GitHub Account

Visit github.com and create your free account.

Step 2: Create a New Repository

Click the New Repository button and enter your project name.

Step 3: Initialize Git

Open your project folder in VS Code and open the terminal.

git init

Step 4: Add Your Files

Add all your project files to Git.

git add .

Step 5: Commit Your Changes

Save your changes with a commit message.

git commit -m "First commit"

Step 6: Connect to GitHub

Connect your local project to your GitHub repository.

git remote add origin YOUR_REPOSITORY_URL

Step 7: Push Your Project

Upload your project files to GitHub.

git branch -M main git push -u origin main

Congratulations!

You have successfully pushed your first project to GitHub. You can now manage and share your code online!
